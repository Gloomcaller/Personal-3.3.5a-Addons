# Personal-3.3.5a-Addons

A curated collection of World of Warcraft: Wrath of the Lich King (3.3.5a) addons, pre-configured and ready to use. This repository is updated with my personal addon setup, including all settings and configurations.

## Installation

1. **Download the addons:**
   - Click the green `Code` button
   - Select `Download ZIP`
   - Extract the ZIP file

2. **Install to WoW:**
   - Navigate to your World of Warcraft installation folder
   - Go to `Interface/AddOns/`
   - **Delete or move** any existing addons (optional, recommended for clean setup)
   - Copy **all the folders** from this repository into the `AddOns` folder
   
   *Example path:* `C:\Program Files\World of Warcraft WotLK\Interface\AddOns\`

4. **Launch WoW:**
   - Start World of Warcraft
   - At the character selection screen, click "AddOns" in the bottom left
   - Ensure all addons are enabled (tick the boxes)
   - Adjust settings in-game as needed

- **Pre-configured settings** for optimal WotLK 3.3.5a gameplay
